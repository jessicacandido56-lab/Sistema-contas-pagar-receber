# 💰 Sistema de Contas a Pagar e Receber

Sistema de controle financeiro pessoal desenvolvido para facilitar o gerenciamento de contas a pagar e a receber.

🚧 **Projeto em desenvolvimento**

Atualmente, a aplicação está sendo construída em **Python**, mas novas tecnologias e funcionalidades poderão ser incorporadas conforme o projeto evoluir.

## 🚀 Funcionalidades

- Cadastro de contas a pagar
- Cadastro de contas a receber
- Organização das informações financeiras
- Controle de valores e registros
- Geração de relatórios em Excel

## 🛠️ Tecnologias utilizadas atualmente

- Python
- Excel
- Git
- GitHub

> A stack do projeto poderá ser ampliada ou modificada durante o desenvolvimento.
